APIキーの取り方（3分）
  1. Google Cloud Console → プロジェクト作成
  2. 「APIとサービス」で Maps JavaScript API / Places API (New) / Directions API / Geocoding API を有効化
  3. 「認証情報」→ APIキーを作成
  4. キーの制限 → アプリケーションの制限で ウェブサイト を選び、 https://takase-creator.github.io/* を追加
  5. 上の欄に貼り付けて保存

キーはこの端末のブラウザ内（localStorage）にだけ保存され、どこにも送信されません。個人利用の頻度なら Google の無料枠（SKUごとに月5,000回）に収まります。

ブラウザからヘルスケアを直接読むことはiOSの仕様上できません。書き出したデータを読み込む形で連携します。

  1. iPhoneのヘルスケアアプリ → 右上のプロフィール
  2. すべてのヘルスケアデータを書き出す
  3. できた 書き出したデータ.zip を解凍し、中の export.xml を選択

書き出したCSV／GPXは、ヘルスケアに直接は書き戻せません（iOSの制約）。RunGap・HealthFit などの取り込み対応アプリ経由でヘルスケアに反映できます。

出発地履歴・走行記録・ペース設定・APIキーがこの端末から消えます。
